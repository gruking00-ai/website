# Deployment Guide: OpenCode Web UI to Cloudflare Pages

## Quick Start: Deploy Static Frontend to Cloudflare Pages

### Step 1: Build the Project
```bash
npm install
npm run build
```
This creates `dist/` folder with the static frontend.

### Step 2: Deploy to Cloudflare Pages (Free)

**Option A: Manual Upload**
1. Go to https://dash.cloudflare.com → Pages
2. Create project → Upload files
3. Upload all files from `dist/` folder
4. Your site is live at `https://[project-name].pages.dev`

**Option B: GitHub + Cloudflare Pages (Recommended)**
1. Push to GitHub (requires git installed)
2. In Cloudflare: Pages → Create project → Connect to Git
3. Select your repo
4. Build settings:
   - Build command: `npm run build`
   - Build output directory: `dist`
5. Deploy

## Backend Deployment (Required for Full Functionality)

The backend (`server/index.mjs`) **cannot run on Cloudflare Pages** (static-only hosting).

### Deploy Backend to Vercel (Free Tier)

1. Install Vercel CLI:
   ```bash
   npm install -g vercel
   ```

2. Create `api/index.js` (Vercel serverless):
   ```bash
   # (auto-generated by Vercel from server/index.mjs)
   vercel
   ```

3. Or deploy to Railway/Render:
   - Copy `server/index.mjs` to `index.js`
   - Set start command: `npm start`
   - Environment: Node.js 20+

### Update Frontend to Connect to Backend

Edit `src/lib/api.ts` and update the base URL:
```typescript
const BACKEND_URL = process.env.VITE_BACKEND_URL || window.location.origin

async function fetchJson<T>(path: string, init?: RequestInit): Promise<T> {
  const res = await fetch(`${BACKEND_URL}${path}`, init)
  // ...
}
```

Create `.env.production`:
```
VITE_BACKEND_URL=https://your-backend.vercel.app
```

Rebuild: `npm run build`

## Complete Deployment Checklist

- [ ] Build: `npm run build`
- [ ] Test locally: `npm start` (verify `http://localhost:6090`)
- [ ] Deploy frontend to Cloudflare Pages (`dist/` folder)
- [ ] Deploy backend to Vercel/Railway/Render
- [ ] Update frontend `.env.production` with backend URL
- [ ] Rebuild frontend
- [ ] Redeploy frontend with correct backend URL
- [ ] Test: Open frontend → Create session → Type message → Verify streaming

## Troubleshooting Deployments

**"Failed to fetch from /event"**
- Frontend can't reach backend
- Check CORS is enabled on backend
- Verify backend URL in `.env.production`

**"OpenCode server not found"**
- Backend can't find `opencode` CLI
- Ensure `opencode-ai` is in dependencies (it is)
- Backend starts fresh OpenCode server on startup

**Static 404 on Cloudflare Pages**
- Ensure `dist/` has `index.html`
- Cloudflare Pages auto-serves `index.html` for SPA routes
- Check build output: `npm run build` produces correct `dist/index.html`

## Example: Deploy to Railway (Easiest)

1. Go to https://railway.app
2. New Project → Deploy from GitHub
3. Select your repo
4. Railway auto-detects Node.js
5. Set start command: `npm start`
6. Get URL: `https://your-app.railway.app`
7. Update frontend `.env.production` with this URL
8. Rebuild and redeploy frontend

## Live Example Architecture

```
User Browser
    ↓
Cloudflare Pages (dist/ static files)
    ↓ HTTP requests to /api, /session, /event
Backend on Railway/Vercel
    ↓
Spawns OpenCode server (port 4096 internal)
    ↓
Proxies requests & streams
```

## Local Development

For local testing without deploying:

**Terminal 1: Backend**
```bash
npm install
npm run server
# Runs on http://localhost:6090
```

**Terminal 2: Frontend**
```bash
npm run dev
# Runs on http://localhost:5173
# Proxy configured in vite.config.ts → http://localhost:6090
```

Open http://localhost:5173 in browser.
