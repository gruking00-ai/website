## 🆘 TROUBLESHOOTING

**Git push fails**: Make sure you created personal access token at https://github.com/settings/tokens/new

**Railway deploy fails**: Check Railway dashboard logs → Errors shown there

**Live URL not working**: Railway takes 1-2 minutes to start. Refresh page after 2 min.
